#01_12_clusters_data  
Based on the data of 12 watershed clusters after K-means clustering, each cluster has its own separate CSV file.  

#02_XGBoost-opt-p.ipynb  
The XGBoost prediction model that requires tuning hyperparameters for each cluster. When predicting for each cluster, make sure to modify the input file path, hyperparameters, and output file path.
